# التحقق من إصلاح ربط الإجازات والحضور

مبني على main عند 773067333fcc750d00879ccb6100949b9c215fbc.

## ما تغيّر

- يُستثنى تقاطع الإجازة المعتمدة مع فترة التأخير أو الخروج المبكر قبل التقريب وتطبيق السماح وشرائح التأخير.
- تظل الإجازة المعلقة غير مؤثرة في حساب الحضور.
- بعد التحديث، يعاد حساب مسودات أيام الإجازة الجزئية عند قراءتها أو إعادة حسابها. الأيام المعتمدة تحتفظ بأرقامها السابقة وتُعلّم كتغييرات معلقة حتى يعيد HR فتحها واعتمادها.
- تظهر الإجازة والعطلة الرسمية بحالتيهما في قائمة الحضور والتقارير.
- تفاصيل اليوم تعرض مدة الإعفاء والوقت المطلوب وفترة الإجازة ورقم طلبها والتنبيهات، وتعرض التغيير المعلق حتى عندما يكون اليوم معتمداً.
- تعرض قائمة اليوم والتقرير أيام التعارض التي تحتاج مراجعة، وتستخدم التقارير دقائق العمل المطلوبة المحسوبة في الباك، لا ساعات الدوام العامة.
- لا تعرض الواجهة إمكانية طلب تصحيح ليوم إجازة كاملة أو عطلة أو راحة أو خارج الخدمة؛ الباك يمنع ذلك مسبقاً.

## اختبارات آلية

من eos-backend، بعد التأكد أن إعدادات الاختبارات تتصل بقاعدة الاختبار:

```sh
php artisan test --filter=LeaveAttendance
php artisan test
```

من EOMS Front_End:

```sh
npm test -- --watch=false
npm run build
```

أضيف LeaveAttendanceOverlapTest: 11 حالة ببيانات مختلفة وثلاثة اختبارات للإجازة المعلقة، وترقية يوم معتمد، وحقول الاستجابة وصلاحية التصحيح.

## تجربة يدوية

استخدم موظف اختبار ويوم دوام. السياسة 09:00–16:00، السماح 45 دقيقة، والشرائح المكتملة 60 دقيقة.

1. قدّم إجازة ساعات 11:00–13:00 واعتمدها بحساب HR.
2. تحقق في شاشة الحضور من ظهور طلب الإجازة وفترتها، وقت مطلوب 5:00 وإجازة 2:00.
3. دخول 13:00 وخروج 16:00: تأخير فعلي ومحسوب 120 دقيقة، وعمل 180 دقيقة.
4. دخول 09:00 وخروج 11:00: خروج مبكر 180 دقيقة، وعمل 120 دقيقة.
5. دخول 12:00 وخروج 16:00: تأخير 120 دقيقة، وعمل 180 دقيقة، وتنبيه بصمة داخل الإجازة.
6. دخول 09:45 وخروج 16:00: تأخير فعلي 45 دقيقة، تأخير محسوب صفر، وعمل 255 دقيقة.
7. إجازة كاملة مع بصمة: يبقى اليوم إجازة مع تنبيه تعارض ظاهر، ولا يظهر نموذج تصحيح أوقات الحضور.
8. أضف عطلة رسمية ليوم آخر: تظهر كعطلة رسمية باسمها، وليست يوم راحة.
9. اعتمد يوماً ثم اعتمد له إجازة بأثر رجعي: يظهر تنبيه التغييرات المعلقة مع السجل السابق؛ أعد فتحه ثم راجع حسابه واعتمده.
10. راجع التقرير: يوم الإجازة الكامل لا يضيف وقت عمل مطلوباً، واليوم الجزئي يضيف الوقت المخفّض من الباك. افتح قائمة المراجعة للتأكد من ظهور التعارضات غير المعتمدة.

اعتماد الحضور لا يلغي الإجازة ولا يعيد رصيدها. حسم تغيير الإجازة يخضع لمسار الإجازات وصلاحياته.

## نتيجة التحقق أثناء إعداد التحديث

- اختبارات الفرونت: 72 ناجحة.
- بناء الإنتاج: ناجح؛ يوجد تحذير CommonJS متعلق بمكتبة ExcelJS الموجودة مسبقاً.
- اختبارات PHP لم تُشغّل في بيئة إعداد التحديث لعدم توفر PHP وComposer. يلزم تشغيلها قبل الدمج.
- لا يتضمن هذا التحديث migrations أو تغييرات اعتماديات.
